# ShuTool: Shuttle Priority Pass System

**ShuTool** is a web-based Shuttle Priority Pass System designed to improve the school shuttle experience by making priority requests more organized, convenient, and fair.

In many campuses, students may need to wait until a shuttle is full before it leaves. This can be inconvenient for riders who are in a hurry, such as students who are late for class or need to reach an important destination on time. ShuTool helps solve this problem by allowing riders to send a priority request connected to their shuttle number, so shuttle drivers can immediately see who needs to be prioritized.

## Purpose of the System

The main goal of ShuTool is to provide a simple and efficient platform for managing shuttle priority requests. It helps riders communicate their urgency, helps drivers manage requests more clearly, and helps administrators monitor the overall shuttle process.

## Main Users

### Riders / Passengers

Riders can use the system to:

- Register and log in to their account
- Send a priority request for their assigned shuttle
- Add an optional note, such as “Late for class”
- View the history of their past priority requests
- Use only a limited number of priority requests per day or week to prevent abuse

### Drivers / Shuttle Operators

Drivers can use the system to:

- Log in to their assigned shuttle dashboard
- View real-time priority requests from riders
- See requests linked to their shuttle number
- Mark priority requests as handled once served
- Review past requests for their assigned shuttle

### Admin / System Manager

Admins can use the system to:

- Manage rider and driver accounts
- Create and update shuttle details
- Assign drivers to specific shuttle numbers
- Monitor active and past priority requests
- Deactivate or suspend accounts if users misuse the system

## Key Features

- User registration and login
- Rider priority request submission
- Optional request notes
- Shuttle-based request tracking
- Driver dashboard for real-time requests
- Request history for riders and drivers
- Admin management for users and shuttles
- Account suspension or deactivation for abuse prevention
- Request limits to promote fair use

## System Benefits

ShuTool helps make the shuttle process:

- **More convenient** for riders who need urgent transportation
- **More organized** for drivers handling passenger requests
- **More transparent** for administrators monitoring shuttle activity
- **More fair** by limiting excessive priority request usage

## Conclusion

The Shuttle Priority Pass System provides a practical solution for improving school shuttle operations. By connecting riders, drivers, and administrators in one platform, ShuTool supports a smoother, faster, and more organized shuttle service for the campus community.
